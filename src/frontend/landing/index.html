Được xây dựng cho lập trình viên và doanh nghiệp

Chia sẻ, kiểm thử, phân phối và quản lý ứng dụng một cách an toàn và nhanh chóng mà không cần mở cổng NAT hoặc cấu hình VPN phức tạp.

Dev & Webhook Testing

Nhận URL HTTPS công khai ngay lập tức để thử nghiệm webhook của Stripe, GitHub, Zalo hoặc chia sẻ giao diện web nội bộ với đối tác.

  • Tự động cấp chứng chỉ SSL miễn phí
  • Bảo lưu subdomain ổn định
  • Hỗ trợ chỉnh sửa và lưu cookie

Zero Trust Access

Truy cập SSH, Remote Desktop, quản trị database nội bộ từ xa mà không cần public IP hoặc cấu hình Port Forwarding nguy hiểm.

  • Xác thực đa tầng JWT / API Key
  • Giới hạn băng thông và số kết nối
  • Ghi lại lịch sử truy cập (Audit Logs)

UDP & Game Streaming

Công cụ tối ưu nhất để share máy chủ game (Minecraft, Palworld, CS:GO) hoặc media streaming cục bộ ra ngoài Internet.

  • Chuyển tiếp UDP hiệu năng cao
  • Thuật toán chống nghẽn và suy giảm ping
  • Chế độ file share an toàn bằng mã pin

Quy trình

Kết nối hoạt động như thế nào?

1

Yêu cầu kết nối

Client khởi tạo handshake mã hóa TLS, gửi kèm Client ID và Generation ID duy nhất tới Gateway server.

2

Xác thực & Bảo lưu

Server xác thực thông tin, kiểm tra cơ sở dữ liệu SQLite để gán lại chính xác subdomain và cổng công khai trước đó.

3

Đồng bộ Realtime

Kênh control plane duy trì gửi tín hiệu ping/pong đo RTT. Khi phát hiện mạng yếu, cơ chế backoff + jitter sẽ kích hoạt.

4

Truyền dữ liệu an toàn

Lưu lượng HTTP/TCP được forward qua data plane sử dụng buffer pool tái chế giúp tối ưu hóa bộ nhớ và tốc độ tối đa.

Hỏi đáp

Các câu hỏi thường gặp

Tìm kiếm câu hỏi để giải quyết nhanh các vấn đề cấu hình hoặc lỗi thường gặp.

HTTP Tunnel tự động định tuyến các yêu cầu HTTP/HTTPS qua subdomain được gán cố định (ví dụ: https://my-app.bacsycay.click) và tự động xử lý chứng chỉ SSL. TCP Tunnel cung cấp một IP tĩnh kèm Port công khai ngẫu nhiên (ví dụ: 103.77.246.196:10245) phù hợp cho SSH, RDP hoặc Database.

Khi bạn ngắt kết nối client, server sẽ tự động giữ (reserve) subdomain và cổng của bạn trong cơ sở dữ liệu SQLite trong vòng 5 phút. Nếu bạn kết nối lại trước khi hết hạn, bạn sẽ nhận được chính xác tài nguyên cũ mà không bị thay đổi URL.

Cực kỳ an toàn. Toàn bộ control plane và data plane đều truyền qua cổng mã hóa TLS. Ở phía server, các tính năng brute force protection, giới hạn payload kích thước 10MB và CORS whitelist được cấu hình nghiêm ngặt.
