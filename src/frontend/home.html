Zero Config

Client đã trỏ sẵn về server công cộng. Tải về, chạy một lệnh là có URL public ngay.

Bảo mật TLS

Mã hóa TLS 1.3 cho kết nối control và data. Certificate pinning chống tấn công MITM.

Đa giao thức

TCP, UDP và HTTP. SSH, RDP, game server, web app, database — tất cả đều chạy được.

HTTPS Subdomain

Mỗi tunnel HTTP nhận một subdomain HTTPS riêng dạng id.bacsycay.click.

Chia sẻ file

Biến thư mục thành kho lưu trữ với Web UI và WebDAV, mount thành ổ đĩa mạng.

Hiệu năng cao

Viết bằng Go, tối ưu RAM/CPU, xử lý nhiều kết nối đồng thời ổn định.

Lệnh mẫu

# HTTP tunnel (web app)
./proxvn --proto http 3000
# TCP tunnel (SSH)
./proxvn 22
# UDP tunnel (Minecraft Bedrock)
./proxvn --proto udp 19132
# Chia sẻ file (WebDAV + Web UI)
./proxvn --file . --pass secret --permissions rwx
