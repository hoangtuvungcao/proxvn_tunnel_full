ProxVN Tunnel

Getting Started

Hướng dẫn cài đặt và chạy tunnel đầu tiên của bạn trong 2 phút.

Zero Configuration: Server free public đã sẵn sàng tại 103.77.246.196:8882. Bạn chỉ cần download client và chạy ngay — không cần đăng ký, không cần credit card.

Bước 1: Download Client

Chọn binary phù hợp với hệ điều hành của bạn:

  • Windows: proxvn-windows-amd64.exe
  • Linux x64: proxvn-linux-amd64
  • Linux ARM64: proxvn-linux-arm64
  • macOS Intel: proxvn-darwin-amd64
  • macOS Apple Silicon: proxvn-darwin-arm64
  • Android (Termux): proxvn-android-arm64

Bước 2: Chạy Tunnel Đầu Tiên

1HTTP Tunnel (Web Server)

Ví dụ bạn có web server chạy ở localhost:3000:

# Linux/macOS
chmod +x proxvn-linux-amd64
./proxvn-linux-amd64 --proto http 3000

# Windows
proxvn-windows-amd64.exe --proto http 3000

Client sẽ kết nối server và hiển thị URL public:

HTTP Tunnel Active
Public URL: https://abc123.bacsycay.click
Forwarding to: localhost:3000

2TCP Tunnel (SSH)

Expose SSH server của bạn ra internet:

./proxvn-linux-amd64 22

Kết quả:

TCP Tunnel Active
Public Address: 103.77.246.196:15234
Forwarding to: localhost:22

Người khác có thể SSH vào máy bạn qua:

ssh user@103.77.246.196 -p 15234

3UDP Tunnel (Game Server)

Ví dụ Minecraft Bedrock server:

./proxvn-linux-amd64 --proto udp 19132

Players kết nối qua 103.77.246.196:15678 (port động)

Use Cases Phổ Biến

Web Development

# React dev server (port 3000)
./proxvn --proto http 3000

# Next.js (port 3000)
./proxvn --proto http 3000

# Laravel (port 8000)
./proxvn --proto http 8000

Remote Access

# SSH (port 22)
./proxvn 22

# RDP Windows (port 3389)
proxvn.exe 3389

# VNC (port 5900)
./proxvn 5900

Database Access

# PostgreSQL (port 5432)
./proxvn 5432

# MySQL (port 3306)
./proxvn 3306

# MongoDB (port 27017)
./proxvn 27017

Tùy Chỉnh Nâng Cao

Config File

Tạo file proxvn.json cùng thư mục với binary:

{
"server": "103.77.246.196:8882",
"proto": "http",
"port": 3000,
"ui": true
}

Sau đó chỉ cần chạy:

./proxvn

Background Mode

Chạy client ở chế độ ngầm (không có UI):

# Linux/macOS
nohup ./proxvn --proto http 3000 --ui=false > tunnel.log 2>&1 &

# Windows (PowerShell)
Start-Process proxvn.exe -ArgumentList "--proto","http","3000","--ui=false" -WindowStyle Hidden

Certificate Pinning (Khuyến nghị)

Để bảo vệ kết nối tunnel control, dùng cert pin:

./proxvn --cert-pin 29e1546abeb0e1d27adc57362422670b5347a0f19a847c5e9dda8fa7cd99c6d8 3000

Cert pin của server free: 29e1546abeb0e1d27adc57362422670b5347a0f19a847c5e9dda8fa7cd99c6d8
