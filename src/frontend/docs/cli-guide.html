ProxVN Tunnel

CLI Reference

Hướng dẫn đầy đủ về ProxVN Client — tất cả lệnh, tham số và ví dụ thực tế.

Cài đặt

Tải binary phù hợp với hệ điều hành của bạn:

  • Windows: proxvn-windows-amd64.exe
  • Linux: proxvn-linux-amd64 / proxvn-linux-arm64
  • macOS: proxvn-darwin-amd64 (Intel) / proxvn-darwin-arm64 (Apple Silicon)
  • Android (Termux): proxvn-android-arm64
Server mặc định: Client đã tự động trỏ tới server free 103.77.246.196:8882. Bạn chỉ cần download và chạy ngay.

Cấu hình

Client đọc cấu hình theo thứ tự ưu tiên:

  1. CLI flags (cao nhất)
  2. Config file proxvn.json
  3. Built-in defaults

Config file (proxvn.json)

{
"server": "103.77.246.196:8882",
"proto": "tcp",
"host": "localhost",
"port": 8080,
"ui": true,
"cert_pin": "29e1546abeb0e1d27adc57362422670b5347a0f19a847c5e9dda8fa7cd99c6d8"
}

Đặt file này cùng thư mục với binary hoặc ~/.proxvn/proxvn.json

Các Chế Độ Chạy

1. HTTP Tunneling

Dùng cho Web Server (NodeJS, Python, Apache...). Server sẽ cấp tự động subdomain HTTPS.

# Cú pháp: proxvn --proto http [LOCAL_PORT]
./proxvn --proto http 3000

# Kết quả: https://abc123.bacsycay.click → localhost:3000

2. TCP Tunneling

Chế độ mặc định. Dùng cho SSH, RDP, MySQL, Redis...

# Cú pháp: proxvn [LOCAL_PORT]
./proxvn 22 # SSH
./proxvn 3389 # Remote Desktop
./proxvn 5432 # PostgreSQL

3. UDP Tunneling

Dùng cho Game Server, DNS, VoIP...

# Cú pháp: proxvn --proto udp [LOCAL_PORT]
./proxvn --proto udp 19132 # Minecraft Bedrock
./proxvn --proto udp 1194 # OpenVPN

4. File Sharing Mode

Biến máy tính thành File Server với Web UI và WebDAV.

# Cú pháp: proxvn --file [PATH] --pass [PASSWORD] [OPTS]
./proxvn --file ./share --pass 123456 --permissions rwx

Tham số (Flags)

Flag Mặc định Mô tả
--server 103.77.246.196:8882 Địa chỉ Server Tunnel (IP:Port)
--proto tcp Giao thức: tcp, udp, http
--host localhost Host local cần forward
--port 80 Port local (có thể điền trực tiếp)
--id (random) ID định danh client
--ui true Bật giao diện TUI (false = background mode)
--cert-pin (none) SHA256 cert pin để xác thực server
--insecure false Bỏ qua xác thực SSL (chỉ dùng test)
--file "" Đường dẫn thư mục để share
--pass "" Mật khẩu truy cập file share
--permissions rw Quyền file: r (đọc), rw (đọc ghi), rwx (full)
Flag linh hoạt: Flag có thể đặt ở đâu cũng được — proxvn --proto http 3000 --ui=false và proxvn 3000 --proto http đều hợp lệ.

Mẹo & Thủ Thuật

Chạy ngầm (Background)

Trên Linux, dùng nohup hoặc systemd. Tắt UI để log ra file dễ hơn.

nohup ./proxvn --proto http 3000 --ui=false > client.log 2>&1 &

Kết nối Server Riêng (Self-hosted)

Nếu bạn tự host server ProxVN:

./proxvn --server YOUR_VPS_IP:8882 --proto http 80

Certificate Pinning (Bảo mật cao)

Xác thực server bằng cert pin:

./proxvn --cert-pin 29e1546abeb0e1d27adc57362422670b5347a0f19a847c5e9dda8fa7cd99c6d8 3000

Troubleshooting

Lỗi "connection refused"

  • Kiểm tra IP/Port server
  • Thử telnet: telnet 103.77.246.196 8882
  • Kiểm tra firewall

Subdomain không hoạt động

  • Ping thử subdomain: ping abc.bacsycay.click
  • Đảm bảo dùng chế độ --proto http
